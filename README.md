# Fahim — Portfolio 2

A responsive, editorial-style portfolio for an independent graphic designer. Built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Import this repository into Vercel or Netlify. The default build command is `npm run build` and the output directory is `dist`.

## Customize

- Edit project concepts and descriptions in `src/App.jsx`.
- Update colors, typography, and responsive layouts in `src/styles.css`.
